LeetCode53 最大子数组和
题目：整数数组nums，找出连续子数组最大和，子数组至少1个元素，返回最大和。

示例：nums=[-2,1,-3,4,-1,2,1,-5,4]，输出6，子数组[4,-1,2,1]

DP舍弃思想：
dp[i]：以i结尾的连续子数组最大和
转移：dp[i]=max(dp[i-1]+nums[i], nums[i])
舍弃逻辑：若dp[i-1]<0，前面片段是负收益，直接舍弃，子数组从i重新开始；否则拼接前面子数组。
dp[i]只代表以i结尾的局部最优，不是全局答案，遍历中记录所有dp[i]最大值作为结果。

空间优化：dp[i]仅依赖dp[i-1]，无需完整dp数组，只用pre变量保存前一项，空间O(1)。

核心代码
int maxSubArray(int* nums, int numsSize) {
    int res = nums[0];
    int pre = nums[0];
    for(int i=1;i<numsSize;i++){
        pre = (pre+nums[i])>nums[i]?(pre+nums[i]):nums[i];
        if(pre>res) res=pre;
    }
    return res;
}
