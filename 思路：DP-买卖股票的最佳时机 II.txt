# DP做题通用思考流程模板
# 以股票系列dp[i][0/1]为例，不背公式，从题目推导状态

1. 把问题翻译成人话：梳理每天可以做哪些操作？有什么约束？
    示例(股票题约束)：同一时间最多持有1股；买必须发生在卖前面。

2. 枚举【一天结束后所有可能的局面(状态)】，不要漏，不要多。
    示例(股票)：局面只有两种
        局面1：手里不持有股票
        局面2：手里持有1支股票

3. 给每个局面定义dp数组含义，给状态起名字。
    示例：
        dp[i][0]：第i天结束，手里不持有股票，可获得的最大利润
        dp[i][1]：第i天结束，手里持有股票，可获得的最大利润

4. 对每一个状态做逆向推导：
    今天这个局面，可以由昨天什么局面 + 什么动作，转移而来？据此写出状态转移方程。
    示例：
    ①今天不持有股票 dp[i][0]
        来源1：昨天就不持有股票，今天什么都不做 → dp[i‑1][0]
        来源2：昨天持有股票，今天执行卖出 → dp[i‑1][1] + prices[i]
        转移：dp[i][0] = max(dp[i‑1][0], dp[i‑1][1] + prices[i])

    ②今天持有股票 dp[i][1]
        来源1：昨天就持有股票，今天什么都不做 → dp[i‑1][1]
        来源2：昨天不持有股票，今天执行买入
            ·121(最多1次买卖)：之前不能有交易，本金为0 → -prices[i]
            ·122(无限次买卖)：可以使用之前交易的利润 → dp[i‑1][0] - prices[i]
        转移：
            121：dp[i][1] = max(dp[i‑1][1], -prices[i])
            122：dp[i][1] = max(dp[i‑1][1], dp[i‑1][0] - prices[i])

5. 处理初始条件(base case)，第0天的状态。
    股票示例：
        dp[0][0] = 0;         //第0天不买股票，利润0
        dp[0][1] = -prices[0];//第0天买入股票，利润为负的股价

6. 确定最终输出：题目要求的结果，对应哪一个局面的最优值。
    股票示例：最后一天手里持有股票没有实际收益，答案取 dp[n‑1][0]

===== 避坑提醒 =====
❌误区：上来直接背诵转移公式，不去思考为什么是这几个状态。
✅正确思考顺序：允许执行的操作 → 全部合法结局局面 → 定义dp状态 → 推导转移。

补充理解：
如果一维dp数组无法完整保存全部关键信息，就增加维度。
股票题只用一维dp[i]只能记录当天最大利润，但丢失了【当前是否持股】这个关键信息，会导致无法推导后续状态，因此需要二维。
